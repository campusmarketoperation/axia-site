## 1. 受入条件（Acceptance Criteria）

- [ ] AXIA Sign 紹介ページから導入支援コンテンツへの動線が適切に配置されている
- [ ] 試験導入の申し込みフォームへ正確に遷移する（計測パラメータが維持される）
- [ ] 記載内容が最新の料金・機能仕様と乖離していない **[要確認: 社長の最終承認]**

## 2. リンク確認項目

- [ ] 「無料試験導入を申し込む」ボタンの遷移先URLと UTM パラメータが整合している
  - 参考（Shift ページの現状）: `#trial` のページ内リンク（`data-cta="hero_trial"` / `"footer_trial"`）、相談は `/#contact`、LINE は `https://lin.ee/i9Oq13e`
- [ ] 関連 SaaS リポジトリ（Sign / SignLP）へのリンク導線を確認した **[要確認: 遷移先URL]**
- [ ] 全リンクが絶対パス（`/` 始まり、または `https://`）で、404 / リダイレクト崩れがない

## 3. 計測確認項目

- [ ] GA4（`G-GERXXRBW3Q`）でクリックイベントが計測されている
  - 確認イベント例: `product_page_view` / `trial_cta_click` / `demo_cta_click`（`product`, `placement` パラメータ）
  - 確認方法: DevTools の Network で `collect` を絞り込み、GA4 の DebugView / リアルタイムでも確認
- [ ] 無料試験導入導線のコンバージョン計測タグ（`trial_form_start` / `trial_form_submit`）と干渉していない（二重発火・欠落なし）
- [ ] 送信パラメータに個人情報が含まれていない

## 4. 未充足時の修正指示

| 状況 | 対応 |
|---|---|
| リンク不備 | 該当リンクを絶対パスで修正し、再デプロイ |
| 計測不備 | GTM / GA4 の設定を確認し、トリガー設定を再定義 |
| 内容乖離 | 該当箇所を「要確認」フラグのまま非公開設定とし、修正案を再提示 |
